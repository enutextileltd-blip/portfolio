# ALMAS THREAD — Official Portfolio Website

Official digital showroom and portfolio website for **Almas Accessories Industries**, manufacturer & supplier of 100% Export Quality 120/2 Computerized Multi-Head Embroidery Threads in Bangladesh.

---

## 🚀 Features & Technologies
- **Next.js 16 (App Router)** & **Turbopack**
- **Modern Claymorphism UI**: 3D inflated bubble cards, soft glowing depth, and fluid animations
- **800+ Pantone Color Shade Library (`/colors`)**: Interactive search, color family filters, and WhatsApp batch quoting
- **Dynamic Product Pages (`/product/[id]`)**: High-resolution image galleries, technical specs, and instant quote inquiry
- **Dual Location Support**: Factory in Chittagong (Pahartali, Chattagram) and Commercial Showroom in Gazipur, Dhaka
- **Enterprise SEO**: Schema.org JSON-LD (ManufacturingPlant, WebSite, ItemList, FAQPage, Breadcrumbs), OpenGraph, dynamic sitemap XML, and robots.txt
- **Bilingual Interface**: Full English and Bengali (`bn`) localization toggle

---

## 🛠️ Getting Started

First, install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

---

## 🏗️ Production Build

npm run build
